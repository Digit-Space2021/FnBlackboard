FnBlackboard / 飞牛小黑板隐私说明

适用版本：0.5.0；更新日期：2026年11月11日。

FnBlackboard 是运行于用户自有 fnOS 设备上的第三方独立应用。本说明用于解释应用在提供文档、空间、快速记录、统一事项（时间、提醒、确认、责任安排）与多人协作功能时处理的数据。

1. 本地处理的数据

为识别当前用户、文档所有者和共享对象，应用会使用 fnOS 网关提供的用户标识（UID）和用户名。用户创建的文档标题与正文，以及空间、快速记录、统一事项、事项与记录的关联、共享权限、协作状态和历史版本等数据，会保存在 FnBlackboard 自身的 NAS 本地应用数据目录中。

2. 数据用途

上述数据仅用于身份识别、内容保存、空间与成员关系、权限判断、多人协作、事项状态、提醒、版本恢复和应用正常运行。FnBlackboard 当前不包含广告 SDK、行为统计 SDK 或面向开发者的用户画像/跟踪功能。

3. 网络访问与主动反馈

当用户主动提交“帮助与反馈”表单时，应用通过所配置的 HTTPS 接口将用户自行填写的反馈类型、目的、内容、选填联系方式和必要的应用环境信息发送至开发者反馈接收服务。开发者服务端以 SQLite 保存反馈，并尝试通过飞书发送通知。飞书通知失败不影响已保存的反馈。应用不会因反馈而自动上传文档标题或正文、快速记录内容、事项内容、空间名称、成员名称、访问令牌、Cookie、密码等数据。使用反馈功能并非使用其他功能的前提。

应用当前不向开发者自动上传匿名使用统计，亦不自动收集日志附件。

用户主动点击“检查项目版本”时，应用会访问 GitHub Pages 上的 FnBlackboard 版本清单；用户选择查看新版时，可跳转至公开的 GitHub Release 页面。该过程不会由 FnBlackboard 自动安装或替换应用。访问 GitHub 服务时，GitHub 可能按照其自身政策处理网络连接信息（例如 IP 地址和浏览器请求信息）。

4. 空间与多用户共享

个人空间仅包含其所有者；家庭/团队空间可由空间所有者添加成员。文档仍按照文档自身的共享规则控制访问。应用不会在未经用户主动创建空间、添加成员或设置共享规则的情况下主动向其他 NAS 用户公开内容。

5. 保存与删除

数据保存在用户自己的 NAS 上，直至用户在应用内删除相应内容，或在卸载 FnBlackboard 时选择彻底删除应用数据。升级安装前建议单独备份应用数据目录，避免设备故障或误操作导致数据丢失。来源记录与正式事项相互独立；删除来源记录不必然删除关联事项，删除事项也不会直接删除其他独立记录。若卸载时选择保留数据，相关本地数据会继续保存在设备上，以便后续重新安装后使用。

6. 第三方组件

FnBlackboard 使用 Vue、Tiptap、Yjs、Gorilla WebSocket、SQLite 相关 Go 组件、飞书与钉钉官方SDK等第三方开源软件。应用包内提供 THIRD_PARTY_NOTICES.txt，列明构建时使用的第三方运行时组件及其许可信息。

7. 自愿赞赏

“关于”页面可展示微信/支付宝赞赏二维码。二维码图片随应用静态提供，是否扫码完全由用户决定；FnBlackboard 不在应用内收集或保存支付账号、银行卡或交易凭据。扫码后的支付流程由相应支付服务提供方处理。

8. 联系与反馈

普通用户可使用应用内“帮助与反馈”自愿提交问题与建议，也可联系反馈邮箱 Digit_Space@163.com，或加入 QQ 用户交流群（群号以应用内展示为准）。

项目公开页面：github.com/Digit-Space2021/FnBlackboard。GitHub 不作为普通用户必须使用的反馈渠道。

10. 可选消息接入、Agent授权与自动规则

用户自行配置并启用飞书、钉钉或企业微信原生渠道后，NAS会主动连接相应平台，使用用户填写的应用凭据进行平台认证。仅处理已配对发送人及允许会话范围内的文字消息，原文保存至该用户的NAS个人待确认列表；平台账号标识、消息标识、配对期限和处理回执用于身份对应、去重、撤销与审计。回执发送至对应平台会话；平台接受不表示设备已读或事项提醒已送达。第三方平台对其服务内数据的处理受其自身说明约束。

原生应用密钥和会话回复地址使用NAS独立密钥加密保存，读取配置不返回密钥；接入/只读访问令牌以哈希校验，配对指令仅显示一次。用户可停用渠道、撤销配对和Agent凭据；已有记录与审计独立保留。NAS数据备份包含私密内容及恢复所需密钥，应由用户妥善保管。

只读OAuth流程需要用户在已登录的NAS独立窗口核对并明确同意，只授予所选的已有读取权限，不授予创建、修改、删除或通知权限。授权过程可读取客户端的公开HTTPS元数据，不向该元数据地址发送NAS文档、消息原文或访问令牌。授权码、访问凭据均有期限并支持撤销。

严格个人自动创建默认关闭。用户明确启用后，符合精确日期时间及“提醒我”格式的低风险私有消息可转为个人事项；原文、来源与自动处理记录保留。风险表达、群消息与共享安排继续人工确认；撤销不能收回已发送的第三方通知。日历及本地提醒的核心计算不依赖外部平台连接。

11. 通用Agent授权与确认创建

除上述兼容只读流程外，通用Agent可在独立授权页申请用户勾选的查询、提醒收取与逐次确认后的个人内容创建能力。浏览器在已登录账号下选择权限，以PKCE、随机state、NAS签名的短时一次性授权码连接；NAS保留连接标识、权限、期限、撤销及操作记录。凭据仅用于该用户已有可见范围，不授予管理NAS或代替他人的权限。

通用技能ZIP不包含私密令牌。连接后的凭据由Agent电脑的操作系统安全存储保管，不以明文写入技能包；NAS按连接配置保存加密凭据或校验信息。Agent可读取已授权的数据并转交用户选择的Agent服务处理，该服务的数据政策由其提供方负责。通过Agent确认属于用户委托，NAS不能独立证明第三方聊天中的人类发言；每次创建仍需核对摘要，并在写入前复核有效授权。用户可在设置中撤销连接。

12. 日历文件、图片与今日卡片

用户主动选择的ICS文件在NAS解析并展示预览，确认后才保存支持的事项及本人提醒。导出的日历文件包含用户选择的事项和本人的提醒内容，交给其他日历服务后由该服务处理。文档图片按文档权限保存在NAS应用目录，不自动上传至开发者服务。

一键今日卡片在浏览器独立窗口使用当前NAS登录，定时读取本人今日内容；断网时可保留窗口中的上次显示，关闭浏览器停止刷新。可选独立Python客户端使用单独的最小今日只读凭据，安全保存在运行设备。节假日仅在用户主动刷新时向固定第三方数据源请求年份等必要参数，不发送事项、提醒或文档正文。
